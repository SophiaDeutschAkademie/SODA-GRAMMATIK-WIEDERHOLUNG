# SODA GRAMMATIK WIEDERHOLUNG

Sophia Deutsch Akademie의 독일어 문법 복습 웹앱이에요. 표지, 목차, 나레이션이 들어간 Lektion 01–16 애니메이션으로 구성돼요.

## 구조

- `index.html` : 표지와 목차 (한 페이지 안에서 전환, 주소 끝에 `#toc`)
- `lektionen/lektion-01.html … lektion-16.html` : 각 Lektion 애니메이션
- `assets/` : 로고, 글꼴, 이미지, 나레이션 음원(mp3)

## 배포 (GitHub Pages)

Settings → Pages에서 Branch를 `main`, 폴더를 `/ (root)`로 선택하고 Save를 누르면 돼요.
